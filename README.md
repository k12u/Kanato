# Kanato

ひらがなで打った日本語の文章を、あとからまとめて漢字かな交じり文に変換する macOS アプリです。

```
きょうのかいぎでけっていしたしようをらいしゅうまでにじっそうする
→ 今日の会議で決定した仕様を来週までに実装する
```

変換したい範囲を選んで、メニューかキーボードショートカットから「Kanatoで変換」を実行するだけです。入力中に変換候補を選ぶ必要はありません。

## 特徴

- **この Mac の中で変換**: かな漢字変換専用モデル zenz をアプリ内で動かします。選択した文章が外部に送信されることはありません
- **いろいろなアプリで使える**: macOS の「サービス」の仕組みを使うため、TextEdit・VS Code・Slack など、サービスに対応したアプリでそのまま使えます
- **元の文章を壊さない**: 変換に失敗したときは選択範囲を書き換えず、ビープ音でお知らせします

## 動作環境

- macOS 14 以降（動作確認は macOS 27）
- 変換モデルの保存に約 70 MB の空き容量
- 初回のモデルダウンロード時のみインターネット接続

## インストール

現在、配布用のビルド（署名済みのアプリや DMG）は用意していません。ソースコードから Xcode でビルドしてください。手順は [開発者向けドキュメント](docs/development.md#ビルドと起動) を参照してください。

## はじめに

### 1. 変換モデルをダウンロードする

Kanato を起動すると設定ウィンドウが開きます。「**ダウンロードして使う**」を押すと、変換モデル（zenz-v3.2-small、約 70 MB）を公式の配布元（Hugging Face）から取得し、この Mac に保存します。

ダウンロードが終わったら「**動作テスト**」で、変換できることを確認できます。

### 2. サービスを有効にする

macOS では、新しく追加されたアプリのサービスは最初は無効になっています。

1. 「システム設定 > キーボード > キーボードショートカット…」を開く
2. 左の一覧から「サービス」を選び、「テキスト」の中の「**Kanatoで変換**」にチェックを入れる
3. 同じ画面で、好きなキーボードショートカットを割り当てておくと便利です

## 使い方

1. 任意のアプリでひらがなの文章を入力し、変換したい範囲を選択する
2. メニューの「アプリ名 > サービス > **Kanatoで変換**」を選ぶ（または割り当てたショートカットを押す）
3. 選択範囲が変換結果に置き換わります

設定ウィンドウを閉じても Kanato は動き続け、次の変換をすぐに受け付けます。終了するときは Kanato を前面にして ⌘Q を押してください。

## うまく動かないとき

- **サービスメニューに「Kanatoで変換」が出ない**: 「はじめに」の手順 2 でチェックが入っているか確認し、Kanato を一度起動してから、使いたいアプリを再起動してください
- **ビープ音が鳴って何も変わらない**: 変換に失敗しています。モデルがダウンロードされていない場合は、自動で設定ウィンドウが開きます。長すぎる文章（4000 文字超）は変換できません
- **ターミナルで変換結果が後ろに追加される**: ターミナルは選択範囲の置き換えに対応していないため、元の文字が残ったまま変換結果が入力されます

## 対応アプリ

TextEdit・VS Code・Slack・Claude・Codex で動作を確認しています。そのほかでも、macOS のサービスに対応したアプリであれば使えます。サービスに対応していないアプリでは使えません。

## 知っておいてほしいこと

- 変換中（通常は一瞬、最大で十数秒）は、使っているアプリの操作が一時的に止まります。macOS のサービスの仕様によるものです
- 選択した文章・変換結果は、保存したりログに記録したりしません

## 外部の LLM サーバーを使う（上級者向け）

LM Studio などの OpenAI 互換 API を持つ LLM サーバーで変換することもできます。設定ウィンドウの「詳細設定」で変換エンジンを「外部 API」に切り替え、API Base URL と Model ID を入力して「保存」してください。

外部 API を使うと、変換のたびに選択した文章を設定したサーバーへ送信します。この Mac 以外のサーバーを指定した場合は、設定ウィンドウに警告が表示されます。
